# TODO manager
Расширение для vscode, которое ищет TODO-комментарии в рабочей области и позволяет удобно по ним ориентироваться.

Автор - Варламов Никита Денисович (ИТМО М3101 558498)

## Описание расширения
Расширение регистрирует TreeView, в котором на верхнем уровне находятся файлы, в которых найдены соответствующие комментарии, а дочерние элементы этих файлов - сами комментарии. На каждый комментарий можно нажать, это откроет файл на нужной строке.

Поиск по проекту осуществляется в первый раз при активации расширения, повторно - по нажатии кнопки обновления с заголовке TreeView.

Команда, которая повторяет поиск (ее активирует кнопка) - `todo-manager.refresh`.

Поддерживается конфигурация исключений в settings.json с помощью glob patterns:
```json
"todo-manager.excludePatterns": [
    "**/node_modules/**",
    "**/.git/**",
    "**/dist/**",
]
```

**Важно:** поддерживаются только single workspace. Если не открыто не одной папки, или открыто несколько, расширение выдаст сообщение об этом.

### Процесс разработки и использование vscode API
При активации расширения в коде выполняется функция activate. В ней инициализируются и передаются объекты TreeView и команды.

Все объекты: представления, команды (те, которые должны быть доступны для вызова из command palette), кнопки, меню и т. д. декларируются в файле package.json.

Был написан класс `TodoTreeDataProvider`. Он реализует интерфейс `vscode.TreeDataProvider<vscode.TreeItem>`. В нем было переопределено два метода: `getChildren` и `getTreeItem`. Второй просто возвращает входные данные и в контексте данного проекта нужен просто чтобы корректно реализовать интерфейс, а первый возвращает дочерние элементы некоторого TreeItem. Если на вход подается `undefined`, это значит, что требуется вернуть элементы верхнего уровня.

Были написаны классы, представляющие файлы и комментарии в боковой панели: FileWithTodo и TodoComment. Именно их возвращает `TodoTreeDataProvider.getChildren`.

Кнопка refresh вызывает команду `todo-manager.refresh`. Текст-заглушка в tree view указан в `package.json`. Поддерживаемые языки программирования захардкожены.

Поддерживается настройка исключений в `settings.json`. Чтобы их парсить, используется метод `vscode.workspace.getConfiguration`. Для поиска файлов используется `vscode.workspace.findFiles`. Открытие файла на нужной строке использует команду, вызов которой недоступен из command palette.
